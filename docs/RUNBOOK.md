# 温室值班值班操作

交班时先打开灌溉配水单，记下页尾运行指纹。重排配水前先看「补灌放行清单」：根区缺读棚区由系统按遥测断档、根区过湿和历史证据三道联锁裁决，只有「准予补灌」的棚区给出保守放行额度，挂起棚区不得人工补水。清单下方的泵班排入量才是实际补灌，未排升数顺延复核，不能当作已补。

需要调整处置量时，在工作台输入已确认的班次配水额度，查看变更后的灌溉配水单，再从「根区读数」核对相关环节。补灌裁决按业务日封档，同一天重跑不会改变放行结论与额度；迟到补报的数据只在之后的重算中生效，不追改当天结论。

没有加载到样例时，先检查 `/health`。若健康接口已恢复，刷新页面并重新提交本班额度。输入超限会得到 `INVALID_SCENARIO`，页面保留上一次有效结果。

复核记录可通过工作台下载。导出包含前台展示的全部批次结果及七个环节的证据，便于按运行指纹对照。
